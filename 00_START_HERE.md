## 🐛 TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| "ModuleNotFoundError: sklearn" | `pip install scikit-learn` |
| "No such file: Mall_Customers.csv" | Check file is in data/ folder |
| "Permission denied" on outputs | Check write permissions |
| Charts not showing | Wait 30 seconds for render |
| Wrong number of clusters | Change OPTIMAL_K in main.py |

See **QUICKSTART.md** for more troubleshooting!
