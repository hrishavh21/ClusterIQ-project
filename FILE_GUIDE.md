## 💻 Python Code Files

### 1. **main.py** ⭐ THE MAIN SCRIPT
**Purpose:** Complete clustering analysis executable  
**Content:**
- Data loading and exploration
- Data cleaning functions
- Feature preprocessing
- Cluster optimization analysis
- K-Means clustering execution
- Visualization generation
- Results saving

**How to run:**
```bash
python main.py
```

**Execution time:** ~30 seconds

**What it does:**
1. Loads Mall_Customers.csv
2. Cleans data (missing values, duplicates, outliers)
3. Tests k=2 to k=10 clusters
4. Generates 3 PNG visualizations
5. Saves clustered data to CSV
6. Prints detailed analysis to console

**Size:** 16 KB

**Key functions:**
- `load_and_explore_data()` - Load CSV and show statistics
- `clean_data()` - Remove duplicates, detect outliers
- `prepare_features()` - Select and standardize features
- `find_optimal_clusters()` - Test different k values
- `plot_optimization()` - Create elbow/silhouette plots
- `perform_clustering()` - Run K-Means algorithm
- `plot_clusters_2d()` - Create 2D visualizations
- `plot_3d_and_silhouette()` - Create 3D and quality plots
- `analyze_clusters()` - Print cluster statistics
- `save_results()` - Save output files

---

### 2. **config.py** ⚙️ CONFIGURATION
**Purpose:** Customizable settings for the analysis  
**Content:**
- File paths (input/output)
- K value to use
- Visualization settings
- Data preprocessing options
- Output options
- Cluster naming

**How to use:**
Edit values before running main.py:
```python
# To use 4 clusters instead of 5:
OPTIMAL_K = 4

# To change figure quality:
FIGURE_DPI = 150  # Lower = smaller files

# To rename clusters:
CLUSTER_NAMES = {
    0: "My Name 1",
    1: "My Name 2",
    ...
}
```

**Size:** 3.8 KB

**Customizable settings:**
- `INPUT_FILE` - Where to find CSV
- `OUTPUT_DIR` - Where to save results
- `OPTIMAL_K` - Number of clusters (default 5)
- `RANDOM_STATE` - Reproducibility
- `PLOT_STYLE` - Matplotlib theme
- `COLOR_PALETTE` - Color scheme
- `FEATURES` - Which columns to analyze
- `KEEP_OUTLIERS` - Include or exclude outliers

**⚠️ Note:** Currently this file is not used by main.py. To use it:
```python
# Add to top of main.py:
from config import *
```

**Content:**

**Excluded files:**

- `.png` files - Optional (large files)

**Note:** Files in .gitignore won't upload to GitHub. Good for:
- Keeping repos small
- Not sharing sensitive data
- Not uploading large generated files
